## 任务管理

| 功能 | 入口 | 说明 |
|------|------|------|
| 创建任务 | 管理台 → 任务管理 → 新增 | 配置调度类型、Handler、参数、路由策略、阻塞策略、超时、重试次数等 |
| 编辑任务 | 管理台 → 任务管理 → 编辑 | 修改任务配置（运行中的任务不停止，下次触发生效） |
| 删除任务 | 管理台 → 任务管理 → 删除 | 同时清除关联日志（代码层面需确认是否级联） |
| 启动/停止任务 | 管理台 → 任务管理 → 启动/停止 | 修改 `trigger_status`，0=停止不调度，1=运行参与调度 |
| 手动触发任务 | 管理台 → 任务管理 → 执行一次 | 跳过时间轮，直接进入 TriggerPool，可传自定义参数和指定执行器地址 |
| 查看任务列表 | 管理台 → 任务管理 | 按执行器分组、触发状态、描述、Handler、作者过滤分页查询 |

## 调度类型

用户在创建任务时选择触发方式：

| 调度类型 | 说明 |
|---------|------|
| `NONE` | 不自动调度，只能通过"执行一次"手动触发或 API 触发 |
| `CRON` | 按 Cron 表达式定时触发（7 位，支持秒级） |
| `FIX_RATE` | 按固定间隔（秒）循环触发，以上次触发时间为基准 |

## 任务执行模式（GLUE 类型）

| 模式 | 说明 |
|------|------|
| BEAN | Handler 以 Spring Bean 形式部署在执行器，用 `@XxlJob` 注解注册，最常用 |
| GLUE(Java) | Java/Groovy 源码托管在调度中心数据库，下发给执行器运行时编译执行 |
| GLUE(Shell) | Shell 脚本托管，执行器写临时文件后调用系统 sh 执行 |
| GLUE(Python) | Python 脚本托管，执行器调用 python 命令执行 |
| GLUE(PHP) | PHP 脚本托管 |
| GLUE(Node.js) | Node.js 脚本托管 |
| GLUE(PowerShell) | PowerShell 脚本托管 |

GLUE 模式支持在线编辑、版本管理（版本历史存 `xxl_job_logglue` 表），无需重新部署执行器。

## 路由与调度策略

用户在创建任务时配置：

- **路由策略**：10 种，决定任务发给执行器集群中哪个节点（FIRST / LAST / ROUND / RANDOM / CONSISTENT_HASH / LFU / LRU / FAILOVER / BUSYOVER / SHARDING_BROADCAST）
- **阻塞策略**：同一任务并发触发时的处理方式（串行排队 / 丢弃 / 覆盖）
- **调度过期策略**：调度时间已过时是否补偿触发（DO_NOTHING / FIRE_ONCE_NOW）
- **超时控制**：执行器侧 FutureTask 限时，超时后 interrupt 并标记失败
- **失败重试**：失败后自动重新触发，最多重试配置次数

## 日志与监控

| 功能 | 说明 |
|------|------|
| 查看调度日志 | 管理台 → 调度日志，可按任务、执行器、时间、状态过滤；每条日志含触发信息和执行结果 |
| 查看执行器日志 | 在日志详情页，Admin 拉取执行器本地日志文件内容（`/log` 接口分页拉取） |
| 数据统计 | 管理台首页 Dashboard：今日运行/成功/失败任务数，过去一段时间的趋势图 |
| 日志清理 | `JobLogReportHelper` 按 `xxl.job.logretentiondays`（默认 30 天）自动清理过期日志 |

## 告警

| 功能 | 说明 |
|------|------|
| 邮件告警 | 任务执行失败时，向 `alarm_email` 字段配置的邮箱发送告警邮件（内置 `EmailJobAlarm` 实现） |
| 自定义告警渠道 | 实现 `JobAlarm` 接口，注册为 Spring Bean，`JobAlarmer` 自动发现并调用 |

## 执行器管理

| 功能 | 说明 |
|------|------|
| 查看执行器分组 | 管理台 → 执行器管理，展示所有执行器分组及当前在线实例地址 |
| 手动录入执行器地址 | address_type=1 时，手动维护地址列表，不走自动注册 |
| 自动注册 | address_type=0 时，执行器启动后自动注册，Admin 每 30s 刷新在线列表，90s 无心跳则剔除 |

## 用户与权限

| 功能 | 说明 |
|------|------|
| 用户管理 | 管理台 → 用户管理，支持新增/编辑/删除用户 |
| 角色控制 | 管理员（role=1）可访问所有执行器；普通用户（role=0）只能访问 permission 字段中配置的执行器分组 |
| 登录鉴权 | 基于 xxl-sso，Session Token 存储在数据库 `xxl_job_user.token` |
| 多语言 | 支持 `zh_CN` / `zh_TC` / `en`，通过 `xxl.job.i18n` 配置 |

## 子任务

在任务配置的 `child_jobid` 字段填写逗号分隔的任务 ID。父任务执行成功（handleCode=200）后，`JobCompleter` 自动触发子任务，支持多个子任务串联。

---

## 分片广播

选择路由策略 `SHARDING_BROADCAST` 时，同一任务广播到所有在线执行器，每个执行器通过 `XxlJobHelper.getShardIndex()` 和 `getShardTotal()` 获取自己负责的数据分片，实现数据并行处理。

---

## GLUE 在线编辑与版本管理

- 管理台支持 GLUE 模式任务的在线代码编辑
- 每次保存生成一个版本记录（`xxl_job_logglue`）
- 版本历史可回滚查看（具体保留版本数见 `XxlJobLogGlueMapper.xml`，文档称 30 版）
